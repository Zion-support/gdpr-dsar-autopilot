# GDPR DSAR Autopilot — Zion AI App Network

Automate Data Subject Access Requests end-to-end: intake, identity verification, data discovery across systems, redaction, and deadline tracking (GDPR/LGPD/CCPA).

**Live app:** https://ziontechgroup.com/gdpr-dsar-autopilot/
**Free AI Discovery:** https://ziontechgroup.com/discovery/
**Network hub:** https://github.com/Zion-support/zion-app-network

## Features
- 30-day deadline countdown with escalation alerts
- Connectors to CRM, email, storage for data discovery
- AI redaction of third-party personal data
- Audit log for every request
